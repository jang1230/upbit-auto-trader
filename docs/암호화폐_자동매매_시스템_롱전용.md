## 시스템 개요

### 🎯 공통 시스템 구조

모든 전문가는 동일한 분석 프로세스를 따르지만, 각 지표에 부여하는 가중치가 다릅니다.

### 📊 7가지 기술적 지표 (모든 전문가가 분석)

1. **RSI (상대강도지수)** - 과매수/과매도 측정
2. **MACD (이동평균수렴확산)** - 모멘텀 측정
3. **Bollinger Bands (볼린저 밴드)** - 변동성 측정
4. **Funding Rate (펀딩비율)** - 선물 시장 심리
5. **Volume (거래량)** - 시장 참여도
6. **Trend (추세)** - 가격 방향성
7. **Fear & Greed (공포탐욕지수)** - 시장 심리

### 🧮 매수 결정 프로세스

1. **1단계**: 각 지표가 매수 신호 + 강도(0-100) 생성
2. **2단계**: 전문가의 가중치 적용
3. **3단계**: Long 점수 계산
4. **4단계**: 신호 결정 (Long 점수가 임계값 이상 → LONG)
5. **5단계**: 신뢰도 계산 (Long 점수 / 전체 가능 점수 × 100)
6. **6단계**: 신뢰도가 임계값 이상 → 진입! (10분 타임프레임 기준 60% 이상)

## 데이터 수집 및 처리

### 📊 캔들 데이터란?

**1개 캔들 = 특정 시간 동안의 가격 요약**

예시: 2025-01-11 14:00~14:10 (10분 캔들)
```
┌─────────────┐
│ 시가: 96,000│ (14:00 첫 거래가)
│ 고가: 97,500│ (10분 동안 최고가)
│ 저가: 95,800│ (10분 동안 최저가)
│ 종가: 97,200│ (14:10 마지막 거래가)
│ 거래량: 120.5│ (10분 동안 총 거래량)
└─────────────┘
```

### 🕐 우리가 사용하는 것: 10분 캔들 100개

```javascript
const candles = await upbitService.getCandles(symbol, 10, 100);
//                                              심볼  ↑   ↑
//                                                  10분  100개
```

**최근 100개 = 10분 × 100 = 1,000분 = 약 16.7시간**

실제 데이터 예시:
```
2025-01-11 14:00~14:10  ← 1번째 캔들 (가장 오래됨)
2025-01-11 14:10~14:20  ← 2번째 캔들
2025-01-11 14:20~14:30  ← 3번째 캔들
...
2025-01-12 05:30~05:40  ← 99번째 캔들
2025-01-12 05:40~05:50  ← 100번째 캔들 (가장 최신)
```

### ⏱️ 실시간 업데이트 방식

✅ **실제 동작 방식:**

```
매 1분마다 Cron Job 실행
    ↓
업비트 API 호출 (1번)
    GET /v1/candles/minutes/10?market=KRW-BTC&count=100
    ↓
응답: 최근 16.7시간 동안의 10분 캔들 100개
    [
      { open: 95000, high: 96000, low: 94000, close: 95500, volume: 120.5 },
      { open: 95500, high: 97000, low: 95000, close: 96800, volume: 135.2 },
      ...
    ]
    ↓
이 100개로 RSI, MACD 등 계산
    ↓
10명의 전문가가 판단
    ↓
1분 후 다시 반복 (새로운 100개)
```

### 💡 왜 10분 캔들인가?

**장점:**
- ✅ 노이즈 제거 (1초 단위는 너무 지저분)
- ✅ 데이터 효율적 (틱 데이터는 너무 많음)
- ✅ 기술적 지표 계산에 적합
- ✅ 단기 트레이딩에 최적 (30분 보유)

**다른 타임프레임과 비교:**
- 1분 캔들: 너무 잦은 신호 (노이즈 많음)
- 10분 캔들: 우리 선택 ✅ (균형)
- 1시간 캔들: 신호가 너무 느림
- 1일 캔들: 장기 투자용 (우리는 단기)

## 기술적 지표 분석

### 🧮 각 지표가 실제로 어떻게 계산되는지

#### 1️⃣ RSI (상대강도지수) - 과매수/과매도

**필요 데이터:** 최근 100개 캔들의 종가만

**계산 로직:**
1. 최근 14개 캔들의 가격 변화 계산
2. 상승폭 평균 / 하락폭 평균 = RS
3. RSI = 100 - (100 / (1 + RS))

**예시:**
```
종가: [95000, 96000, 94000, 97000, ...]
    ↓
상승: [1000, 0, 3000, ...] → 평균 1500
하락: [0, 2000, 0, ...] → 평균 800
    ↓
RS = 1500 / 800 = 1.875
RSI = 100 - (100 / 2.875) = 65.2
```

**매수 신호 생성:**
- RSI < 30 → LONG (과매도, 강도: (30-RSI)/30*100)
- 30-40 → 약한 LONG 신호
- 40-60 → NEUTRAL

#### 2️⃣ MACD (모멘텀 지표)

**필요 데이터:** 최근 100개 캔들의 종가만

**계산 로직:**
1. EMA12 (12일 지수이동평균) 계산
2. EMA26 (26일 지수이동평균) 계산
3. MACD = EMA12 - EMA26
4. Signal = MACD의 9일 EMA
5. Histogram = MACD - Signal

**예시:**
```
종가들로 계산 →
EMA12: 96,500
EMA26: 95,800
MACD: 700
Signal: 500
Histogram: 200
```

**매수 신호 생성:**
- MACD > Signal → LONG (강도: |Histogram| × 10)
- MACD 골든크로스 발생 → 강한 LONG 신호

#### 3️⃣ Bollinger Bands (변동성 밴드)

**필요 데이터:** 최근 100개 캔들의 종가 + 현재 가격

**계산 로직:**
1. MA20 (20일 이동평균) 계산
2. 표준편차(σ) 계산
3. 상단밴드 = MA20 + (2 × σ)
4. 하단밴드 = MA20 - (2 × σ)
5. 현재 가격 위치 = (현재가 - 하단) / (상단 - 하단)

**예시:**
```
MA20: 96,000
σ: 1,000
상단: 98,000
하단: 94,000
현재가: 95,000
위치: (95,000 - 94,000) / 4,000 = 0.25 (25%)
```

**매수 신호 생성:**
- 위치 < 0.2 (하단 근처) → LONG (강도: (0.2-위치)/0.2*100)
- 하단 밴드 터치 후 반등 → 강한 LONG 신호

#### 4️⃣ Volume (거래량)

**필요 데이터:** 최근 100개 캔들의 거래량만

**계산 로직:**
1. 최근 10개 캔들의 평균 거래량 계산
2. 현재 거래량 / 평균 거래량 = 비율

**예시:**
```
최근 10개 평균: 1,000 BTC
현재 거래량: 2,500 BTC
비율: 2.5
```

**매수 신호 생성:**
- 비율 > 1.5 (거래량 급증) + 상승 추세 → LONG (강도: (비율-1)*50)
- 비율 < 0.5 (거래량 급감) → NEUTRAL (약한 신호)

#### 5️⃣ Trend (추세)

**필요 데이터:** 최근 100개 캔들의 종가 + 현재 가격

**계산 로직:**
1. MA20 (20일 이동평균) 계산
2. MA50 (50일 이동평균) 계산
3. 현재가 vs MA20 vs MA50 비교

**예시:**
```
현재가: 98,000
MA20: 97,000
MA50: 95,000
```

**매수 신호 생성:**
- 현재가 > MA20 > MA50 → LONG (강한 상승 추세)
  강도: ((98k-97k)/97k + (97k-95k)/95k) × 10 = 약 30

#### 6️⃣ Funding Rate (펀딩비율)

**현재 상태:** ⚠️ 임시로 중립(40) 고정

```javascript
// 현재 코드

  return { signal: 'neutral', strength: 40 };
}

// TODO: 실제 구현 필요

// - 펀딩비율 < -0.1% → LONG (매수 기회)
```

#### 7️⃣ Fear & Greed Index (공포탐욕지수)

**현재 상태:** ⚠️ 임시로 중립(40) 고정


#### 1️⃣ RSI 전문가 📊 (Expert #1)

**전략:** RSI 과매수/과매도 중심 - 극단적인 지표 활용

**10분 타임프레임 가중치 (트레이딩 아레나 기준):**

- MACD: 0.65
- Bollinger: 0.50
- Volume: 0.60
- Funding: 0.50
- Trend: 0.40
- Fear&Greed: 0.15

**매수 진입 기준:**
- RSI 30 이하 + 다른 지표 매수 신호 → LONG 진입
- 신뢰도 50% 이상일 때만 진입

**예시 계산:**
```
RSI: long(85) × 0.70 = 59.5점 (RSI 25, 과매도!)
MACD: long(65) × 0.65 = 42.25점
Volume: long(70) × 0.60 = 42점
---
Long 점수: 143.75
→ LONG 진입! 신뢰도 82%
```

**성격:** 과매도 구간을 노리는 반등 매수 스타일
