### 유의사항

- 호가 단위 변경은 KRW 마켓에만 적용되며, BTC・USDT 마켓은 해당되지 않습니다.
- **기존에 등록된 주문은 취소되지 않으며**, 신규 주문의 경우 변경된 호가 단위로 제출할 수 있습니다.
- 2025년 07월 31일 이전에 제출된 변경 전 호가단위의 주문은 호가창 내 노출될 수 있으며, 해당 주문은 직접 취소하지 않을 경우 Taker 주문에 의해 체결될 수 있습니다.
- 호가 단위에 맞지 않는 주문을 요청할 경우 다음과 같은 에러가 발생할 수 있습니다 (`invalid_price_bid`, `invalid_price_ask`)

```json
{
  "error": {
    "name": "invalid_price_bid",
    "message": "주문가격 단위를 잘못 입력하셨습니다. 확인 후 시도해주세요."
  }
}
```
