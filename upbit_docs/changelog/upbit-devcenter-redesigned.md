# [안내] 업비트 개발자 센터 문서 개편 안내 (8/14 완료)

안녕하세요, 업비트 개발자센터입니다.

보다 쉽고 편리한 업비트 API 연동 환경을 제공하기 위해, 8월 14일자로 업비트 개발자 센터가 개편되었습니다.

다양한 튜토리얼 콘텐츠와 기능이 지속적으로 업데이트 될 예정이오니 많은 관심 부탁드립니다.

***

## 주요 변경사항

### **업비트 개발자 센터 메인 페이지 UI/UX 개편**

- 개발자 센터의 주요 콘텐츠를 한눈에 확인하고 필요 문서로 더 쉽고 빠르게 이동할 수 있습니다.

### 레시피(Recipe) 기능 신규 오픈

- 언어 별 주요 코드 예제를 단계별로 쉽게 확인하실 수 있도록 새롭게 [레시피](https://docs.upbit.com/kr/recipes) 메뉴를 제공합니다.

### Upbit Historical Market Data 서비스 오픈

- [Upbit Historical Market Data](https://upbit.com/historical_data/main) 페이지에서 업비트 시세 데이터를 편리하게 다운로드 받을 수 있습니다.

### 가이드 문서 보강

- **주요 용어 안내** 가이드 추가
  - 본 개편으로 개발자 센터에서 사용되는 일부 주요 용어들이 변경되었습니다.  
    (예시) 종목 → 페어(Trading Pair)
  - 기존 사용자들의 혼선을 방지하고 신규 사용자의 이해를 돕기 위해 [용어 안내](https://docs.upbit.com/kr/docs/terms) 가이드를 신규 제공합니다.
- **시작하기** 카테고리 신설
  - [API Key 발급 안내](https://docs.upbit.com/kr/docs/api-key), [업비트 API 첫 호출하기](https://docs.upbit.com/kr/docs/first-quotation-api-call), [개발 환경 설정 가이드](https://docs.upbit.com/kr/docs/dev-environment) 등 업비트 API를 처음 연동하는 업비트 회원님들을 위한 가이드 문서들을 보강하였습니다.
- **튜토리얼** 카테고리 신설
  - 시세 조회, 지표 산출, 주문 생성 및 관리, 입금 관리, 출금 요청 및 관리 등 주요 튜토리얼 가이드와 예제 코드로부터 보다 다양한 유스케이스를 확인하실 수 있습니다.
- **자주 묻는 질문 및 가이드** 카테고리 재구성
  - 기존 ‘자주 묻는 질문’ 문서에서 제공되던 QnA 내용을 질문 카테고리별로 분류하여 보다 찾기 쉽게 제공합니다.
  - 마켓별 주문 정책, 출금 허용 주소 등록 가이드, 자전거래 체결 방지 기능 안내 등, API 사용에 참고할 수 있는 가이드 문서들을 이제 해당 카테고리에서 제공합니다.

### API Reference 문서 개편

- **업비트 API 사용 안내** 카테고리 신설
  - [업비트 API 개요](https://docs.upbit.com/kr/reference/api-overview)를 비롯하여 [인증](https://docs.upbit.com/kr/reference/auth), [요청 수 제한](https://docs.upbit.com/kr/reference/rate-limits)와 같은 API 공통 안내 사항을 이제 API Reference 에서 제공합니다.
  - [REST API 사용 안내](https://docs.upbit.com/kr/reference/rest-api-guide), [WebSocket 사용 안내](https://docs.upbit.com/kr/reference/websocket-guide) 문서를 새롭게 제공합니다. API 사용과 관련한 주의 사항 및 안내 내용을 각 문서에서 한눈에 쉽게 확인하실 수 있습니다.
- 각 **API Reference 문서 UI 및 예제 코드 제공 방식** 개편
  - 파라미터와 응답 필드 설명 보강 및 응답 예시 형식을 표준화하고, 통일성 있는 용어를 사용하도록 반영하여 API 명세 가독성을 개선하였습니다.
  - 요청 파라미터에 실시간으로 예시 값을 넣어보고, 그에 따라 변경되는 언어별 예제 코드를 실시간으로 확인할 수 있습니다.
  - 보다 정교한 구현을 위한 다양한 응답 및 에러 예제를 추가하였습니다.

***

## 참고 사항

- 본 개편으로 인한 업비트 API 사양 및 기능의 변경은 없으며 기존 연동 방식에 영향을 주지 않습니다.
- 일부 문서의 URL이 변경되었으나, 기존 문서 URL로도 동일 문서로 접근하실 수 있도록 URL 리다이렉트 정책을 적용하였습니다.
- 일부 API Reference의 문서 제목이 변경 되었습니다. API 컨벤션 및 용어 표준화 작업의 일환으로 진행되었으며, API 기능 변경은 없습니다.  
    (예시) 주문하기 → 주문 생성, 출금 리스트 조회 → 출금 목록 조회, 시세 종목 조회 → 페어 목록 조회 등

***

업비트 개발자 센터는 앞으로도 안정적이고 편리한 개발 환경을 제공할 수 있도록 지속적으로 개선해 나가겠습니다.

감사합니다.
