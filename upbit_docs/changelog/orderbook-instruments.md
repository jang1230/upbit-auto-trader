# [안내] '호가 정책 조회' 기능 추가 (7/31)

`신규기능` `호가정책조회` 

안녕하세요, 업비트 개발자 센터입니다.

호가 정책 조회 (`GET /v1/orderbook/instruments`) 기능이 추가되어 안내드립니다.

자세한 내용은 [호가 정책 조회 문서](https://docs.upbit.com/kr/v1.5.9/reference/%ED%98%B8%EA%B0%80-%EC%A0%95%EC%B1%85-%EC%A1%B0%ED%9A%8C)를 확인해주시길 바랍니다.

***

### 주요 내용

**호가 정책 조회** API는  **페어별로 적용되는 호가 단위**(`tick_size`) 및 **호가 모아보기 단위**(`supported_levels`)정보를 제공합니다. 새로운 호가 정책 조회 API를 통해 주문 전 각 종목의 호가 단위를 손쉽게 확인할 수 있어, 주문 오류를 방지하는 데 도움이 됩니다.

- 기존 **호가 모아보기 단위 정보 조회**(`/v1/orderbook/supported_levels`) Deprecated 되었으며, 기존 기능 삭제 일정은 추후 별도 공지 예정입니다.
- 정상적인 주문을 위해서는 **종목별 호가 단위를 반드시 확인**해야 합니다.
- 호가 단위에 맞지 않는 주문을 요청할 경우 다음과 같은 에러가 발생할 수 있습니다 (`invalid_price_bid`, `invalid_price_ask`)

```json
{"error":{"name":"invalid_price_bid",
 "message":"주문가격 단위를 잘못 입력하셨습니다. 확인 후 시도해주세요."}}
```

***

### 유의사항

원화 마켓 호가 단위가 변경될 예정입니다. 자세한 내용은 [원화 마켓 호가 단위 변경 안내 공지](https://docs.upbit.com/kr/changelog/krw_tick_unit_change_250731)를 확인해주시길 바랍니다.
